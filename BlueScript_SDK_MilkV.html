BlueScript Pro SDK v6.0 Turbo

Turbo Edition — Specialized for Milk-V Duo S (Dual-Core RISC-V @ 1GHz @ 512MB RAM).

Turbo VM Architecture NEW

v6.0 PRE-COMPILED

The Turbo engine replaces traditional interpretion with a two-pass compilation system, delivering 10-20x performance gains.

1. Two-Pass Compiler

Scripts are tokenized during init(). Labels, commands, and variable names are pre-resolved to integer IDs, eliminating runtime string lookups.

2. Postfix Math (RPN)

All expressions are converted to Reverse Polish Notation (RPN). The stack-based evaluator in evaluateExpr bypasses expensive recursive parsing.

3. Display List Acceleration

The :onDraw loop records commands into a binary Display List once per frame. The system then replays these commands at native speed across all UI stripes, completely decoupling script execution from pixel rendering.

Lifecycle & Language

:onDraw ACCELERATED Rendering loop — recorded to Display List
:onUpdate Logic loop — runs before draw at 10-20x speed
:onMouseEvent Sets event_type, event_x, event_y
:onKeyboardEvent Sets event_type, event_value 
# Variables & Expressions
LET x = 10, y = 20, z = 30           # multi-LET
LET label = "Heap: " + mem_free + " MB" # string concat
LET blink = (second + (minute * 60)) % 2 # parentheses + nested math

IF (score + bonus) > 100 THEN
  IO.PRINT "High score!"
ENDIF
FOR i = 0 TO 10 STEP 2
  Graphics.DrawCircle 200, 150, i * 5, CYAN
NEXT

Operators: + - * / % ( ) — Expressions support unlimited nesting and unary negation. Variable access is O(1).

Syntax Best Practices

  • One Command Per Line: High-density scripts (using : for multi-command lines) are deprecated.
  • System RAM Optimization: The interpreter leverages the Duo S's 512MB RAM. Manual bank switching is not required.
  • Logic in onUpdate: Place collision detection and math in :onUpdate for maximum performance.
